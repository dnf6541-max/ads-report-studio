# ADS 사고분석 리포트 스튜디오

NHTSA SGO ADS CSV와 검수 기록으로 작성하는 독립형 분석 리포트입니다. 기존 `project-1` 및 대시보드와 연결하지 않으며 기존 프로그램의 코드·설정·데이터를 변경하지 않습니다.

## 포함된 기능

- 사고유형·충돌대상·시간/조명·발생환경 분석
- 실제 중상(Serious)·사망(Fatality) 사례와 원문 근거
- 사고 당시 ADS 운행상태 및 피해수준 비교
- 보행자·자전거·이륜차·스쿠터 등 사고 분석
- 국내 공식 통계의 별도 발표 스냅샷
- 기간/보고 회사 필터, 자동차 8유형 연도별 상세표
- 원문·변수 조회, 재현 가능한 무작위 표본과 검산
- CSV 불러오기·다운로드, 페이지/전체 5페이지 PDF

## 실행 및 배포

서버 API나 데이터베이스가 없는 정적 앱입니다. 저장소 루트를 GitHub Pages의 `main` 브랜치 `/ (root)`로 지정합니다. 모든 자산은 상대 경로를 사용합니다. 외부 폰트·추적 서비스·API 키를 사용하지 않습니다.

로컬에서는 HTTP 서버로 루트 폴더를 열어 확인합니다. `file://`로 직접 열면 모듈·압축 데이터 로드가 제한될 수 있습니다.

자동 검증: Node.js 22 이상에서 `node --test verify.mjs`.

## 자료와 단위

제공 ADS 최신/이전 양식 CSV 총 3,890개 원본 기록을 사용합니다. 비사고 정기보고 3개를 제외하고 보고번호별 최신 버전 3,450개를 유지한 뒤 기존 검수의 사고·차량 연결 결과를 적용합니다. 대표 기록 3,060개 중 ADS 시스템 비교 대상은 3,031건이며 사고 당시 ADS 운행 확인은 2,752건입니다. 이는 사고·차량별 대표 보고 건수로, 반드시 물리적으로 고유한 사고 수나 피해 인원과 같지 않습니다.

- 기간: 2021년 7월~2026년 9월에 발생한 확인 대상, 자료 스냅샷 2026-10-15.
- 주간: 신고 시각 06:00–17:59 / 야간: 18:00–05:59. 시간 불명은 별도.
- 조명: Lighting 기재 및 Unknown이 아닌 경우만 분모에 포함. 시간으로 결측 보완하지 않음.
- Serious/Fatality와 Moderate를 분리. 입원 여부만으로 중상에 편입하지 않음.
- 운행상태: 시스템·양식별 상태 변수와 사고 경위의 선후관계를 확인한 기존 검수 결과. 키워드만으로 새 보고를 판정하지 않음.
- 회사별 주행거리 분모가 없으므로 사고율·과실·대책 효과를 추정하지 않음.

## 새 CSV를 넣을 때

데이터·분석 기준 → ADS CSV 선택. 최신/이전 양식별 한 파일씩 최대 두 개를 선택합니다. 한 파일만 선택하면 다른 양식은 유지합니다. 파일은 브라우저 메모리에서 처리하며 서버로 전송하지 않습니다. 새로고침하면 배포된 기본 데이터로 돌아갑니다.

최신 보고의 분석 필드와 검수에 사용한 경위 버전 모두의 SHA-256이 일치할 때만 기존 검수 결과를 재사용합니다. 새 보고, 값/버전 변경, 연결 멤버 누락, 동일 사고·차량 식별자의 새 보고는 재검토 대상입니다. 기존 검수와 일치하지 않는 보고를 확인된 ADS 사고에 자동 편입하지 않습니다.

공통 보고번호/버전의 값이 파일 사이에서 충돌하면 업데이트를 중단합니다. 검수 결과는 `data.json.gz` 안의 `reviews`에 보고 연결, 판정 근거, 경위 버전, 지문으로 보관됩니다. 새로운 사고의 운행상태 및 세부유형 검수는 담당자가 원문을 확인한 뒤 갱신해야 합니다. 검수 없이 지문만 다시 생성하면 안 됩니다.

영구 갱신: 검토를 완료한 새 `data.json.gz`에 대해 `node encode-package.mjs /path/to/data.json.gz`를 실행한 뒤 `data-part1.mjs`, `data-part2.mjs`, `data-base64.mjs`를 이 저장소에 커밋하면 Pages가 새 버전을 게시합니다. 세 파일은 gzip 데이터를 손실 없이 텍스트로 보관한 것으로 원본 복원 결과가 동일합니다. 브라우저의 ‘현재 데이터 패키지 저장’은 파일을 내려받을 뿐 자동으로 GitHub에 쓰지 않습니다. 원본 기준 지문(`baselineHashes`)과 예상 건수는 원본 재현 검사에 사용하므로 임의로 갱신하지 않습니다.

## 검증

`verify.mjs`는 총계·연도별 집계·유형·심각도·VRU·시간 경계·다중 접촉·CSV 파싱·SHA 지문·수정 보고의 격리·신규 연결·중복 충돌·표본 추출·실제 인용문을 검사합니다. 앱의 검산 페이지는 현재 필터에 대한 합계 검사와 원문 추적을 제공합니다. 무작위 표본에 보이는 분류는 기존 검수 결과이며 독립적인 사람의 재검토를 대체하지 않습니다.

## 출처

- [NHTSA Standing General Order](https://www.nhtsa.gov/laws-regulations/standing-general-order-crash-reporting): 제공 ADS CSV 2개와 기존 검수 기록. 불필요한 VIN 형식 문자열은 비식별 처리했습니다.
- [한국교통안전공단, 국내 자율주행차 사고통계 최초 공개](https://main.kotsa.or.kr/portal/bbs/report_view.do?bbscSeqn=18739&menuCode=05010200): 2025-11-28 발표. 2022~2025년 9월 112건. 국내 페이지는 미국 필터와 별도인 공식 발표 스냅샷이며 실시간 자료가 아닙니다.
- PDF: html2pdf.js (MIT), 라이선스 파일 동봉. 브라우저 안에서 PDF를 생성합니다.
