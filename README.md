## 후보 선택과 인력 표기

`Driver / Operator Type`: `In-Vehicle (Commercial / Test)`는 차내 담당자, `In-Vehicle and Remote (Commercial / Test)`는 차내＋원격 담당자입니다. 보고된 인력 위치·구성이며 실제 제어 주체나 원격운전 여부가 아닙니다. 2026년 ADS 운행 확인 기준 각각 113건, 6건입니다. 차내 운전자와 안전관리자를 이 항목만으로 분리하지 않습니다.

## 장소 분류와 전체 사례 개략도

두 원본 CSV 모두 `Roadway Type`을 수집합니다. 기본 검수 대상 3,031건의 실제 값은 일반도로 1,928, 교차로 779, 주차장 228, 고속도로 85, 회전교차로 7, 주차건물 1, 비포장도로 1, `Unknown` 2건입니다. 미기재·양식에 열 없음은 각각 0건입니다. 2026년 검수 대상 978건 중 실제 `Unknown`은 1건입니다.

요약 그래프에서 알려진 장소를 ‘그 외 도로·불명’으로 합치지 않습니다. 상세 도로 유형과 연도별 표를 제공하며, `미상으로 신고`·`미기재`·`양식에 열 없음`을 각각 보존합니다. 취약도로이용자 분석도 교차로, 그 외 명시 장소, 미상·미기재를 구분합니다. 도로 유형의 기재와 정확한 사고 주소·좌표 공개 여부는 별도입니다.

중상·사망 14건과 선택한 기여 가능성 후보(전체 134 / 우선 6 / 확장 128)를 개략도 카드로 표시합니다. 진로가 확인된 19개 고유 사례는 사고 상황도, 확장 후보는 원자료의 양쪽 접촉부위 그림을 제공합니다. 후자는 도로·진로·간격을 임의로 재구성하지 않습니다. 각 목록의 ‘전체 사례 PPTX / PDF / PNG 묶음’은 선택한 기준·필터에 해당하는 모든 사례를 1건당 1페이지로 출력합니다. 기본 6페이지 요약 리포트에는 대표 중상·사망 사례 4건을 유지합니다. 개략도는 원문 경위에 근거한 설명용이며 실측 현장도는 아닙니다.

ADS 미운행으로 분리된 234건의 전체 경위를 확인했습니다.

| 경위에서 확인한 구분 | 건수 |
|---|---:|
| 차내 수동전환 | 176 |
| 원격 직접 제어 | 5 |
| 수동운행, 전환 과정 불명 | 28 |

원격 직접 제어 5건은 원격 운전 4건과 기어 조작만 확인된 1건입니다. 원격 운영자 존재 또는 remote assistance는 직접 운전으로 바꾸지 않습니다. `Driver / Operator Type=None`은 운전업무 담당자 없음이며 물리적 무인 또는 승객 없음의 확정값이 아닙니다.

차내 수동전환 176건 중 충돌까지 시차 구분이 가능한 것은 16건: 보고값 5초 이내 7, 5초 초과 9, 시차 구분 미확인 160. 이전 19개 시간 표현 중 단순 ADS 해제 2건과 수동 지속시간·중간 동작 2건을 제외하고, 명시된 0.8초 전환 1건을 추가했습니다. 근사값·하한을 보존합니다.

전환 계기는 원문에 이유가 연결된 경우만 분류합니다. 176건 중 사유 미명시 129건. 복수 사유로 전체 사유 합계는 177건이며, 전환 사유를 사고 원인이나 결함으로 확정하지 않습니다.

## 중상·사망 사례와 위치

사고 상대: 승용차 5, SUV 3, 자전거 2, 보행자 2, 긴급차량 1, 이륜차 1. `Crash With`와 실제 부상 당사자는 별도입니다. 첫 충돌·후속 접촉·피해자·자료 제공 여부·추가 확인 자료를 모든 14건에 연결했습니다.

14건 모두 개략도를 제공합니다. 도로 배치·차량 위치·설명을 편집하고 SVG로 저장할 수 있으며 PPTX에도 도형으로 출력됩니다. 개략도는 보고 경위의 설명용 배치이며 실측 도로·방향·간격이 아닙니다.

제공 CSV의 14건 주소·위경도는 비공개 처리되어 있습니다. 도시는 표시하되 실제 사고 지점으로 표시하지 않습니다. 별도 출처로 확인한 좌표와 HTTPS 출처 URL을 함께 등록하면 지도 링크를 제공합니다. 도시 검색 링크는 사고 지점 확인이 아닙니다. 편집값은 해당 브라우저와 데이터 패키지에 보존하며 경위 버전이 달라지면 자동 이월하지 않습니다.

## 자율차 기여 가능성 우선검토

기존 원인 기여 분석을 대조하여 원문에 문제가 명시된 6건을 좁은 우선검토 대상으로, 나머지 128건을 기동·접촉 경위의 확장 후보로 제공합니다. **6건 또는 134건을 자율차 과실 전체 건수로 사용하지 않습니다.** 나머지를 무과실로 처리하지 않습니다.

우선검토는 ADS 기능·사고 후 대응 4건 + 바퀴 분리 2건. 최고 피해수준은 부상 보고 없음 4, 경상 1, 중상 1입니다. 차량·외부환경·운영별 예방 가설과 실제로 보고된 수정 조치를 구분합니다. 모든 2,752건의 기존 ID·버전·경위·인용·피해수준 일치를 대조했고 이번에는 우선 6건과 경계 20건의 전체 경위를 다시 읽었습니다. 전체 저심각도 전수 원인 판정은 완료된 상태가 아닙니다.

## 지속 업데이트

현재는 분석 초안 확정 단계입니다. 별도 LLM API 서버의 배포와 키 연결은 다음 단계로 보류했습니다. 현재 사이트는 LLM을 호출하지 않으며 API 키를 포함하지 않습니다.

CSV를 교체하면 같은 근거의 검수 판정은 재사용하고 집계·인사이트의 수치는 자동 갱신합니다. 신규·변경 사고는 재검토 대상으로 분리합니다. 공개 사이트가 검수 없이 새 경위를 확정하는 기능은 없습니다. 다음 단계는 서버의 경위 추출 초안 → 원문 인용·버전 검증 → 담당자 검수 → 분류표·그림·인사이트 갱신 구조입니다.

원본 SHA·분석 필드·경위 버전이 맞아야 기존 판정을 적용합니다. 새 관련 보고가 생기거나 같은 ID·버전 값이 다르면 기존 연결을 재검토합니다. `현재 데이터 패키지 저장`은 다운로드만 하며 GitHub에 자동 업로드하지 않습니다. 검수된 패키지는 `node encode-package.mjs /path/to/data.json.gz`로 변환한 뒤 data-part1/2, data-base64 파일을 이 저장소에 반영합니다.

## 검산과 실행

Node.js 22+에서 `npm install` 후 `npm test`. 핵심 집계·원문·환경·분류는 `node --test verify.mjs verify-extended.mjs`로 오프라인 검증합니다. PPTX 테스트에는 PptxGenJS 4.0.1, JSZip 3.10.1을 사용합니다.

앱 내 검산에서는 합계, 분모, 보고 연결, 원문 인용·버전 및 기준 건수를 대조하며 실패하면 내보내기를 중단합니다. 추가 검토 JSON에 234건 운행상태 검토, 충돌 형태의 166건 모호·부정 표현 검토, 두 차례 층화 난수 표본 96회(고유 82건), 보완한 9건을 기록했습니다. 표본은 품질 검토용이며 정확도의 통계 추정이 아닙니다.

GitHub Pages에서 저장소 루트의 index.html을 배포합니다. 모든 모듈은 상대 경로입니다. 새 모듈·데이터를 먼저 배포하고 index.html을 마지막에 반영합니다. 브라우저 캐시를 피하도록 모듈 버전 쿼리를 함께 갱신합니다.
